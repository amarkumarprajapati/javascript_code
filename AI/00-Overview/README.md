# 🗺️ Roadmap Overview & Checklist

A practical roadmap for a MERN/JavaScript developer who wants to learn AI application development first and **Python + fine-tuning later**.

---

## 🎯 Goal

Build real AI applications using **JavaScript/TypeScript first**.

Later, move into:
- Python
- PyTorch
- Hugging Face
- LoRA / QLoRA
- Fine-tuning
- Model training

> **Important:** Do not try to learn every AI framework at once. Learn the concepts first, then use one tool/framework at a time.

---

## 📅 Suggested Learning Priority

### Stage 1: Core Web & APIs
```text
TypeScript ──> Next.js ──> LLM APIs
```

### Stage 2: Deep Model Control
```text
LLM fundamentals ──> Structured output ──> Streaming ──> Tool calling
```

### Stage 3: Retrieval & Storage
```text
Embeddings ──> MongoDB Vector DB ──> RAG Pipeline
```

### Stage 4: Advanced Systems
```text
Agents ──> Model Context Protocol (MCP) ──> Local LLMs (Ollama)
```

### Stage 5: Python & Model Training (Later)
```text
Python ──> PyTorch ──> Hugging Face ──> LoRA / QLoRA ──> Fine-tuning
```

---

## ❌ Don't Learn These Yet

Until you finish the core AI application path, don't spend time on:
- Training LLMs from scratch
- Advanced PyTorch & CUDA programming
- Advanced mathematics / calculus
- Fine-tuning massive models without domain use cases
- Learning 5 competing vector databases simultaneously
