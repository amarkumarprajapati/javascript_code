# Introduction to DSA

Data Structures = ways to store data
Algorithms = steps to solve a problem using those structures

## Why DSA matters
- Write efficient code
- Pass coding interviews
- Solve real-world problems (search, sort, cache, route)

## How to learn
1. Understand concept
2. Implement in JavaScript
3. Solve 5–10 problems on LeetCode / GFG
4. Move to next topic

## Prerequisites
- Basic JavaScript (functions, loops, arrays, objects)
- Console to run code (`node filename.js`)

## How to use this folder
- Read the markdown theory
- Type every code example yourself
- Solve the practice problems listed at the end of each file
- Do not skip recursion — it is the foundation
