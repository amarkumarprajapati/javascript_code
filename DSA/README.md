# DSA Roadmap — Beginner to Pro

## Phase 1: Foundations
- `01-basics/` — Math/logic, time/space complexity, recursion
- `02-arrays/` — Array operations, sorting, searching, pattern programs

## Phase 2: Linear Structures
- `03-linked-lists/` — Singly, doubly, circular
- `04-stacks-queues/` — Stack, queue, deque
- `05-hashing/` — Hash maps, collisions, chaining

## Phase 3: Non-Linear Structures
- `06-trees/` — Binary tree, BST, AVL, traversals
- `07-heaps/` — Min/max heap, priority queue
- `08-graphs/` — Representations, BFS, DFS, shortest paths, MST
- `09-tries/` — Prefix trees

## Phase 4: Algorithmic Thinking
- `10-dynamic-programming/` — Memoization, tabulation, patterns
- `11-greedy-algorithms/` — Greedy approach, proofs
- `12-backtracking/` — State-space tree, pruning

## Phase 5: Advanced
- `13-advanced-ds/` — Segment tree, Fenwick tree, disjoint set
- `14-problem-patterns/` — Sliding window, two pointers, binary search variants

## Phase 6: Interview Prep
- `15-interview-practice/` — Curated problems by difficulty

> All code examples are in JavaScript. Start with `01-basics/01-introduction-to-dsa.md`.
