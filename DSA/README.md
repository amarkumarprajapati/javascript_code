# DSA Learning Path

> A structured, beginner-friendly roadmap to master Data Structures and Algorithms in JavaScript.

## How to use this folder

Follow the order below. Each file is self-contained but builds on previous concepts.

## Curriculum

### 01 - Basics
| # | File | Topic |
|---|------|-------|
| 1 | `01-introduction.md` | What is DSA and why it matters |
| 2 | `02-time-space-complexity.md` | Big O notation and analysis |
| 3 | `03-recursion.md` | Recursion fundamentals |

### 02 - Arrays
| # | File | Topic |
|---|------|-------|
| 1 | `01-array-basics.md` | Array operations and memory model |
| 2 | `02-sorting.md` | Common sorting algorithms |
| 3 | `03-searching.md` | Linear and binary search |
| 4 | `04-array-patterns.md` | Sliding window, two pointers, prefix sum, etc. |
| 5 | `05-array-problems.md` | Curated problem set with approaches |

## Study tips
1. Read the concept, then code the examples by hand
2. Solve the practice problems before looking at solutions
3. Revisit basics after 2 weeks — repetition builds intuition
4. Focus on patterns, not memorizing solutions
